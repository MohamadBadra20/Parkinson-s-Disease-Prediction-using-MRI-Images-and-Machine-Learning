About NeuroVision

A research-oriented interface for AI-assisted Parkinson’s disease analysis.

Our purpose

NeuroVision connects a reproducible neuroimaging workflow with a simple web interface so users can submit compatible resting-state fMRI data and review the resulting model output.

What it analyzes

The current pipeline uses an AAL atlas, extracts ROI-level time series, computes Pearson functional connectivity and sends the resulting feature vector through the configured machine-learning ensemble.

Privacy

Uploaded files are processed temporarily and removed after analysis. Patient metadata is stored in the local SQLite database used by this application. Deployments should add production-grade encryption, access controls and auditing.

Clinical responsibility

The model is a research support tool. Its predictions are not a diagnosis and must be interpreted by qualified professionals together with clinical evidence.
