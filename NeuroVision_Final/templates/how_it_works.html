How the pipeline works

A clear view of the processing stages behind the prediction.

1

NIfTI input

The system accepts a resting-state fMRI .nii or .nii.gz file and checks its extension and size before processing.

2

AAL alignment

The configured AAL atlas is resampled to the submitted fMRI image using nearest-neighbor interpolation so ROI labels remain discrete.

3

ROI time series

Mean signals are extracted from the expected 116 atlas regions across the fMRI time dimension.

4

Functional connectivity

Pearson correlations are computed between the 116 ROI signals. The upper triangle produces 6,670 connectivity features.

5

Model ensemble

The saved preprocessing/model pipelines receive the feature vector. Their positive-class probabilities are averaged to produce the soft-voting probability.

6

Report

The web result shows the classification and probability, with an optional PDF report for documentation.

Important: The model expects the same feature-generation assumptions used during training. A file that merely opens as NIfTI may still be incompatible with the trained model.
